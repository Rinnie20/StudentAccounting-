# StudentAccounting — Система учёта студентов, курсов и успеваемости

## Описание проекта
Веб-приложение для управления студентами, курсами (группами), предметами и оценками. Реализованы три роли:
- **Администратор** — полное управление студентами, курсами, предметами.
- **Менеджер** — выставление и редактирование оценок студентов по предметам.
- **Гость** — просмотр списка курсов, кураторов, студентов курса и оценок группы.

## Технологии
- **.NET 8.0** (ASP.NET Core MVC)
- **Entity Framework Core** (ORM)
- **MySQL** (база данных)
- **Pomelo.EntityFrameworkCore.MySql** (провайдер)
- **Bootstrap 5** + **Font Awesome** (интерфейс)
- **Identity** (аутентификация и роли)

## Запуск проекта

### Требования
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- [MySQL Server](https://dev.mysql.com/downloads/mysql/) (рекомендуется версия 8.0)
- [Visual Studio 2022](https://visualstudio.microsoft.com/) (или любая IDE с поддержкой C#)

### Инструкция по установке и запуску

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/ваш-логин/StudentAccounting.git
   cd StudentAccounting
   ```

2. **Настроить строку подключения к MySQL**
   - Открыть файл `appsettings.json`
   - Изменить параметры подключения в `DefaultConnection`:
     ```json
     "ConnectionStrings": {
       "DefaultConnection": "server=localhost;port=3306;database=StudentAccountingDb;user=root;password=ваш_пароль"
     }
     ```

3. **Восстановить NuGet-пакеты**  
   В терминале (в папке проекта) выполнить:
   ```bash
   dotnet restore
   ```

4. **Создать базу данных и применить миграции**  
   ```bash
   dotnet ef migrations add InitialCreate
   dotnet ef database update
   ```
   > Если используется новая база данных, миграция создаст все таблицы, а при первом запуске автоматически добавятся тестовые данные (курсы, студенты, предметы, оценки).

5. **Запустить приложение**  
   ```bash
   dotnet run
   ```
   Или нажать `F5` в Visual Studio.

6. **Открыть браузер** по адрегу `https://localhost:5001` (или `http://localhost:5000`).

## Возможности приложения

### Администратор
- **Студенты:** добавление, редактирование (с подтверждением пароля `admin` при смене курса), удаление, поиск.
- **Курсы:** создание, редактирование, удаление. У каждого курса есть куратор и описание.
- **Предметы:** добавление, редактирование, удаление. Предмет привязан к конкретному курсу.

### Менеджер
- Выбор курса → выбор предмета → просмотр всех студентов курса с их оценками по выбранному предмету.
- Выставление / изменение оценки (от 2 до 5).
- Отображение среднего балла группы по предмету.

### Гость (неавторизованный пользователь)
- Просмотр списка курсов (название, куратор).
- Для каждого курса доступны:
  - «Список студентов» → ФИО студентов курса, а по кнопке «Подробнее» — полная информация о студенте и его оценки по всем предметам.
  - «Список предметов» → список предметов курса, а по кнопке «Оценки» — средний балл группы по предмету и оценки каждого студента.

## Начальные данные (Seed)
При первом запуске в базу автоматически добавляются:
- 6 курсов (11МЭП, 41МЭП, 12ТМ, 32ТМ, 11ДОУ, 14ДОУд) с кураторами.
- 4 предмета для каждого курса (согласно специальности).
- По 7 студентов на каждый курс (случайные имена, email генерируется транслитерацией).
- Случайные оценки по предметам (от 2 до 5).
